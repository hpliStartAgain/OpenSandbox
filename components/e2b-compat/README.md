# OpenSandbox E2B Compat (Scaffold)

Optional component proposed by [OSEP-0027](https://github.com/opensandbox-group/OpenSandbox/blob/main/oseps/0027-optional-e2b-compatibility.md). Scaffold only: it loads and validates configuration and serves a liveness check. No E2B operation is implemented or tested.

Usage and configuration: [docs/guides/e2b-compatibility.md](../../docs/guides/e2b-compatibility.md)
